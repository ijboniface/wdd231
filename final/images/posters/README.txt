Film cover images

Place locally downloaded cover files in this folder and set the matching posterUrl in data/films.json, for example:

"posterUrl": "images/posters/the-missing-link.jpg"

Use a film-specific original poster when one can be verified. If not, leave posterUrl empty so the site displays its labelled representative artwork. Keep image proportions intact; the Films page uses contain so poster artwork is not cropped.

The Films page includes official YouTube channel links for Mike Ilemobola, John Oguntuase, Felix Bankole and EVOM Channel TV. A direct Watch film link is shown when a specific video URL is available; otherwise, the card links to the associated production channel.
